Inventory Stock Alert System

A Java application that watches stock levels in public distribution shops and raises an alert when an item runs low.

How the alert works

Every time stock is sold, the system compares the quantity left with the item’s threshold. If quantity ≤ threshold, it creates an Alert with the item name and the amount left.

Who uses it

Admin

Adds and removes items and sets the alert threshold for each one.

Shop staff

Records sales and received stock. Sees the alert as soon as an item runs low.

Classes in the code

User
Base class with id, name and role.
Admin
Extends User. Adds items, removes items and sets thresholds.
ShopStaff
Extends User. Sells items and receives stock.
StockItem
One product with its quantity and threshold.
StockManagement
Holds all items and runs the alert check.
Alert
Message and time for one low-stock event.
